# HealerDB Frontend — VS Code-Themed Studio

Next.js 15 client providing a developer-focused IDE interface for HealerDB:
- **VS Code Chrome Architecture**: Activity Bar, collapsible Explorer Sidebar, Editor Tab navigation, Diagnostic Problems tray, and Live Status Bar.
- **Deep Table Profiling**: Interactive anomaly tree inspection with statistical outlier and leak visualization.
- **Remediation Diff Review**: Side-by-side SQL diff previews with testcontainer sandbox results and one-click atomic transactions.
- **Connection Management**: Multi-database target registration and connection switching.
